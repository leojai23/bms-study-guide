Module 3 · Sensors and Field Devices

3.8 Status devices: current switches and DP switches

Week 3 · Day 17About 10 minPage 8 of 8✓ Done
After this page you can
  • Explain why a start command is not proof that equipment is running.
  • Compare the ways of proving a fan or pump is running and what each really proves.
  • Set up a current switch and a fan ΔP switch correctly.
  • Write the logic for fan-fail and unexpected-running alarms.
Warm-up · 3 quick questions from earlier pages (2 min)
  1. List four hard-wired signals between the BMS and a VFD.
    from 3.7 Variable frequency drives (VFD)
    Show answer
    Start (DO), speed reference (AO), run status (DI), fault (DI).
  2. Why are equal-percentage valves used on coils?
    from 3.6 Chilled water valves and actuators
    Show answer
    Coils give most of their output at low flow; an equal-percentage valve compensates, so the combined response is close to linear and the loop is stable at every load.
  3. What is actuator adaptation?
    from 3.5 Damper actuators
    Show answer
    A function where the actuator runs end to end to learn the real stroke of the damper or valve, so 0–100 % maps to the full real movement.
In one line

A status device gives the BMS independent proof that equipment is really running — because a start command only shows what the BMS asked for, not what happened.

?Why it matters

Contactors stick, belts break, drives trip and fans spin backwards. If the BMS only knows what it commanded, it will show a fan as “running” while the floor overheats. Good status devices — and alarms comparing command with status — catch these failures in seconds.

Current switches

A current switch is a small current transformer (CT) clipped round one phase conductor of the motor cable, with a contact that closes when the current rises above an adjustable threshold. Split-core versions clip on without disconnecting the cable.

  1. Run the motor normally and note the current (from the drive display or a clamp meter).
  2. Break the load if you can do so safely — e.g. with the belt removed the motor draws only its no-load current.
  3. Set the threshold between the no-load current and the lowest normal running current. Now a broken belt shows as “not running”.
  4. On VFD motors, use a current switch rated for variable frequency and check it still trips at minimum speed — or read the current from the drive over the network.

Fan ΔP switches

A ΔP switch across the fan — + to the outlet side, − to the inlet — closes when the fan builds pressure. Set it well below the lowest normal running ΔP (at minimum speed) but clearly above zero, so it proves airflow without chattering. Filter ΔP switches use the same device to a different purpose (page 3.3).

Delays matter

Every status check needs a delay: a fan takes a few seconds to prove after a start command, and some seconds to stop. Too short and you get nuisance alarms; too long and failures go unnoticed.

Follow AHU-01

AHU-01 proves its fan with the VFD run relay (DI) — which shows the drive is on — and checks the VFD motor current over Modbus: if the drive runs but the current is close to no-load, the BMS raises a “possible belt failure” alarm. The supply duct pressure sensor gives a third, independent check that air is moving.

⚒On site

  • Find out what the status point is really wired to — an auxiliary contact proves much less than a ΔP switch.
  • Test the proving: stop the fan locally with the BMS command still on — the fan-fail alarm must appear after its delay.
  • Re-check current-switch thresholds after motor or belt changes.
  • For DP switches, check the tubes are on the right sides and not blocked.

✓Check yourself

Try each one before opening the answer.

Fault scenario · what would you do?

An AHU's status comes from the contactor's auxiliary contact. The fan belt snaps at 11:00. What does the BMS show, and how would you prevent this blind spot?

The contactor stays energised and the motor keeps spinning, so the auxiliary contact stays closed. Only a device further down the chain — current above no-load, or fan ΔP — detects the broken belt.

  1. Why is a DO start command not proof that a fan is running?

    Show answer
    It only shows what the BMS asked for. Tripped overloads, Hand switches, broken belts and failed drives all leave the command ON while the fan is not moving air.

  2. Where should a current switch threshold be set?

    Show answer
    Between the motor's no-load current and its lowest normal running current, so a broken belt reads as “not running”.

  3. What does a fan ΔP switch prove that a VFD run relay does not?

    Show answer
    That the fan is actually building pressure — moving air — not just that the drive output is on.

  4. Write the logic for a fan-fail alarm.

    Show answer
    If the start command is ON and run status is OFF for more than the proving delay (e.g. 30 s), raise “fan fail”, stop the fan and lock out until reset.

  5. What does a “running unexpectedly” alarm usually mean?

    Show answer
    The equipment runs while the BMS commands it off — often a Hand switch, a welded contactor, or another system (e.g. fire control) starting it.
