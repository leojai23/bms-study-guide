RS485 rules 5.1

  • Daisy chain only — no stars or spurs
  • 120 Ω at both ends only → A–B ≈ 60 Ω (power off)
  • Bias at one point · use the common wire · screen earthed once
  • 32 unit loads · ~1,200 m per segment · repeaters beyond
  • A/B labels vary — swapping is a safe test

PID and alarms 6.3

  • Gain = 100 % ÷ proportional band
  • P only → offset · I removes it · D rarely in HVAC
  • Hunting → wider PB / longer Ti · sluggish → narrower PB / shorter Ti
  • Alarms: limit + deadband + delay + enable condition + priority + clear message

Safety and fault-finding 4.1

  • Isolate · lock · tag · prove – test – prove
  • BMS “off” is not isolation — fans start remotely
  • VFD DC bus: wait the labelled time
  • Fault-finding: check the point → measure at the controller → split field / controller side
  • Comms: physical → settings → protocol → application
