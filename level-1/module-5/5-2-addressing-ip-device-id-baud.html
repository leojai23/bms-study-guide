Module 5 · BMS Communication Protocols

5.2 IP address, subnet mask, device ID and baud rate

Week 4 · Day 22About 10 minPage 2 of 5✓ Done
After this page you can
  • Explain IP address, subnet mask and default gateway, and decide whether two devices share a subnet.
  • Know the address ranges for Modbus, MS/TP and BACnet device instances.
  • Match serial settings — baud rate, data bits, parity, stop bits — across a bus.
  • Write a simple numbering plan for a building.

In one line

Every device needs a unique address on its network, and everything on one bus must share the same communication settings — get either wrong and devices are invisible or collide.

?Why it matters

Address and settings mistakes are the second big source of communication faults after wiring. They are also the easiest to prevent: a written numbering plan, agreed before anyone configures a device, avoids duplicates and makes every device findable for the life of the building.

⚙How it works

IP addressing in one page

SettingExampleMeaning
IP address10.1.3.21This device's address — unique on the network
Subnet mask255.255.255.0 (/24)Which part of the address is the network: here 10.1.3.x
Default gateway10.1.3.1The router to send traffic to for other subnets
DNS / NTP servers10.1.0.5Name lookup and time synchronisation (if used)

Two devices can talk directly only if they are in the same subnet — the network part of their addresses (decided by the mask) is identical. Otherwise traffic must go through the gateway (router). With a /24 mask, 10.1.3.21 and 10.1.3.140 are neighbours; 10.1.3.21 and 10.1.4.21 are not.

Interactive tool
  • Give BMS controllers static addresses (or DHCP reservations) so they never change.
  • Use private ranges: 10.x.x.x, 172.16–31.x.x or 192.168.x.x.
  • Keep the BMS on its own VLAN or physical network, separate from office IT.
  • In each subnet, the first address (network) and last (broadcast) cannot be used by devices.
  • Know the ports: BACnet/IP uses UDP 47808 (0xBAC0); Modbus TCP uses TCP 502. Firewalls must allow them.

Device addresses

AddressRangeMust be unique…
Modbus server (slave) address1–247 (0 = broadcast)on that serial bus
BACnet MS/TP MAC address0–127 for masters; 128–254 for slaveson that MS/TP segment
BACnet device instance (device ID)0–4,194,302across the whole BACnet internetwork
BACnet network number1–65,534for each network (IP or MS/TP) in the internetwork
Max_Master

On MS/TP, each master passes the token only up to the address set in Max_Master (default 127). If it is set to 31 on some devices, a device at MAC 40 will never get the token and stays invisible. Set Max_Master on every device to at least the highest MAC on the segment.

Serial settings

SettingCommon valuesNotes
Baud rate9,600 · 19,200 · 38,400 · 76,800 (MS/TP) · 115,200Speed in bits per second; identical on every device of a bus
Data bits8Almost always 8
ParityNone · Even · OddModbus RTU's default is Even; many devices ship with None. MS/TP uses None
Stop bits1 (or 2)The Modbus specification uses 2 stop bits when parity is None — but many devices use 1. Match the device

Settings are written in short form: 19200 8E1 = 19,200 baud, 8 data bits, Even parity, 1 stop bit. One device with a different setting does not just fail itself — on some buses it corrupts traffic for everyone.

Follow AHU-01

DDC-AHU-01: IP 10.1.3.21 /24, gateway 10.1.3.1, BACnet device instance 103021. Its private Modbus RTU bus to the VFD: VFD address 1 at 19200 8E1 — the same settings in the controller's port configuration and in the drive's parameters.

⚒On site

  • Agree the numbering plan with IT and every vendor before configuring anything; keep it in the project documents.
  • Label each device with its address and device instance.
  • Use the ping command to test IP reachability before blaming BACnet.
  • When adding a device to an existing bus, read the current settings first — do not assume the defaults.

AKey terms

IP address
Unique address of a device on an IP network.
Subnet mask
Defines which part of an IP address identifies the network.
Default gateway
Router address used to reach other subnets.
VLAN
Virtual LAN — a logically separate network on shared switches.
Device instance
BACnet device identifier, unique across the whole internetwork.
MAC address (MS/TP)
Address of a device on an MS/TP segment, 0–127 for masters.
Max_Master
Highest MS/TP MAC address to which the token is passed.
Baud rate
Serial communication speed in bits per second.
Parity
Simple error check bit: none, even or odd.
8N1 / 8E1
Short form of serial settings: data bits, parity, stop bits.

✓Check yourself

Try each one before opening the answer.

Fault scenario · what would you do?

A new controller is set to 10.1.3.200 with mask 255.255.255.0 and gateway 10.1.4.1. It can talk to devices on Level 3 but the server on another subnet cannot reach it. Why?

A device can only reach a gateway inside its own subnet. With 10.1.3.x/24, the gateway must be a 10.1.3.x address (here the router's 10.1.3.1).

  1. Are 192.168.5.20 and 192.168.6.20 in the same subnet with mask 255.255.255.0?

    Show answer
    No — the network parts are 192.168.5 and 192.168.6.

  2. What range can a Modbus server address use?

    Show answer
    1–247 (0 is broadcast).

  3. Which BACnet identifier must be unique across the whole internetwork?

    Show answer
    The device instance (device ID).

  4. What does 9600 8N1 mean?

    Show answer
    9,600 baud, 8 data bits, no parity, 1 stop bit.

  5. Which UDP port does BACnet/IP use by default?

    Show answer
    47808 (0xBAC0).
