In one line

BACnet is the open protocol designed for building automation: every device describes itself as a set of objects (inputs, outputs, schedules…) with properties, that any BACnet client can discover, read and command.

?Why it matters

BACnet (ASHRAE 135, also ISO 16484-5) is the main open protocol in BMS. Unlike Modbus, a BACnet device tells you what it has — names, units, alarm states — so integration is faster and more reliable. But it has more concepts to understand, and its priority array is one of the most misunderstood features in the industry.

⚙How it works

Devices, objects, properties

Object typeRepresentsExample
DeviceThe controller itself — one per device, with its instance numberDDC-AHU-01, instance 103021

Multi-state Input / Output / ValueSeveral named statesMode: Off / Occupied / Unoccupied / Fire

LoopA PID loop (on some devices)RAT → CHW valve

Each object has properties. The important ones: Present_Value (the value), Object_Name, Units, Status_Flags (in alarm, fault, overridden, out of service), Out_Of_Service (lets you test logic with a simulated value), Reliability, and for commandable objects the Priority_Array and Relinquish_Default.

Services: how devices talk

ServiceUse
Who-Is / I-AmDiscovery: “who is out there?” — each device answers with its instance and address
ReadProperty / ReadPropertyMultipleRead values (many at once is far more efficient)
WritePropertyChange a value or command an output, at a priority
SubscribeCOVAsk a device to report a value only when it changes — less traffic than polling
Event / alarm notificationsDevices report alarms themselves (intrinsic reporting) to the recipients in a Notification Class

The priority array

Commandable objects (outputs and some values) do not just have one value — they have 16 priority slots. Each writer writes into its own slot; the lowest-numbered slot that is not empty decides the output. When every slot is empty (null), the output takes its Relinquish_Default.

PriorityStandard use
1Manual life safety
2Automatic life safety
5Critical equipment control
6Minimum on/off time
8Manual operator
9–16Available for applications — the program and schedules typically use a low priority such as 16 (conventions vary by project)
Release, don't overwrite

To remove an operator override you relinquish it — write null at priority 8. Writing a new value at 8 leaves the override in place, just with a different number, and the program stays locked out. Forgotten writes at high priorities are a classic cause of “the program doesn't work”.

BACnet MS/TP

  • Runs on RS485 (page 5.1). Master-Slave/Token-Passing: masters pass a token around in MAC-address order; only the holder may send.
  • Masters use MAC 0–127; set Max_Master to at least the highest MAC used.
  • Baud rates 9,600–115,200; 38,400 and 76,800 are common. All devices on the segment must match.
  • Cheap and robust for FCU, VAV and other room-level devices; slower than IP.

BACnet/IP, routers and BBMDs

  • BACnet/IP sends BACnet messages in UDP packets, default port 47808.
  • Discovery (Who-Is) uses broadcasts, which IP routers do not forward. A BBMD (BACnet Broadcast Management Device) in each subnet forwards them to the others listed in its broadcast distribution table.
  • A single device outside any BBMD subnet can join as a foreign device by registering with a BBMD.
  • A BACnet router joins different networks — for example BACnet/IP to MS/TP. Every network gets a unique network number.
  • BACnet/SC (Secure Connect) is the newer, encrypted transport using TLS — increasingly specified for cyber-security.
PICS and BTL

A device's PICS (Protocol Implementation Conformance Statement) lists exactly which objects and services it supports. BTL listing shows it was tested by the BACnet Testing Laboratories. Check both when selecting devices for integration.

Follow AHU-01

DDC-AHU-01 is a BACnet/IP device, instance 103021. Its points are BACnet objects: RAT is AI-1, the CHW valve is AO-1, the fan command is BO-1, the RAT setpoint is AV-1, the occupancy schedule is Schedule-1. The program writes the valve at priority 16; an operator override from the graphic writes at priority 8 and must be relinquished afterwards. The FCUs on the floor are on MS/TP behind the supervisory controller, which acts as the router.

⚒On site

  • Discover with a BACnet explorer tool (the free YABE is widely used) to see devices, objects and priority arrays directly.
  • When an output ignores the program, look at its priority array before anything else.
  • Plan network numbers and device instances for the whole site before commissioning.
  • Use ReadPropertyMultiple and COV where available — they cut network load dramatically.

AKey terms

BACnet
Open data communication protocol for building automation (ASHRAE 135 / ISO 16484-5).
Object
A BACnet representation of a point or function, e.g. Analog Input.
Property
An attribute of an object, e.g. Present_Value, Units.
Who-Is / I-Am
Discovery services.
COV
Change of value — reporting only when a value changes.
Priority array
Sixteen command slots; the highest-priority non-null slot sets the output.
Relinquish
Write null to a priority slot, removing that command.
Relinquish_Default
Value used when every priority slot is null.
BBMD
BACnet Broadcast Management Device — forwards broadcasts between IP subnets.
PICS
Protocol Implementation Conformance Statement — what a device supports.
BACnet/SC
Secure Connect — encrypted BACnet transport over TLS.

✓Check yourself

Try each one before opening the answer.

Fault scenario · what would you do?

After commissioning, AHU-01's CHW valve stays at 0 % whatever the PID loop does. The priority array shows 0 % at priority 8 and 62 % at priority 16. What do you do?

A leftover operator override at priority 8 outranks the program at 16. Writing a new value at 8 keeps the program locked out; relinquishing removes the override. Then find out who left it.

  1. Which property holds a BACnet object's current value?

    Show answer
    Present_Value.

  2. What is the difference between polling and COV?

    Show answer
    Polling asks repeatedly; COV subscriptions make the device report only when the value changes, reducing traffic.

  3. Priorities 8 and 16 both hold values. Which wins?

    Show answer
    Priority 8 — the lowest number that is not null.

  4. Why are BBMDs needed?

    Show answer
    Discovery and some services use broadcasts, which IP routers do not pass between subnets; BBMDs forward them.

  5. What does a PICS tell you?

    Show answer
    Which BACnet objects, properties and services a device supports.
