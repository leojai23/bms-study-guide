4.6 Reading BMS drawings and point names

Warm-up · 3 quick questions from earlier pages (2 min)
  1. You measure the correct signal at the controller terminals but the BMS value is wrong. Where is the fault?
    from 4.5 Sensor wiring and troubleshooting
    Show answer
    On the controller side: point configuration (type, range, scaling, offset), an override, or the controller/input itself.
  2. Name the three terminals of a changeover contact.
    from 4.4 Dry contacts, relay outputs, NO and NC
    Show answer
    COM (common), NO and NC.
  3. Describe how a 2-wire transmitter is connected.
    from 4.3 Analog signals: 0–10 V, 4–20 mA, 0–20 mA
    Show answer
    Supply + → transmitter + ; transmitter − → controller mA input; controller input common → supply −. The loop current powers the transmitter.
In one line

BMS drawings and point names are the shared language between designer, installer, programmer and operator — read them first, keep them consistent, and update them when anything changes.

?Why it matters

Every task — wiring, programming, commissioning, fault-finding — starts with a drawing or a point list. A consistent point name lets anyone find “Level 3 AHU-01 return air temperature” on the graphic, the controller, the panel label and the trend log without guessing. Lab 2 asks you to produce exactly this for AHU-01.

Symbols

Reading a control schematic

  1. Read the title block: system, drawing number, revision, and whether it is “for construction” or “as-built”.
  2. Follow the air path (or water path) from inlet to outlet, naming each component.
  3. Find every point bubble and note its tag and I/O type.
  4. Look for interlock lines and notes — fire shutdown, hard-wired safeties.
  5. Cross-check against the point list: every bubble should appear there, and every list entry on the schematic.

Point naming

Conventions differ between companies and projects, but good ones share these rules:

  • Fixed order — from big to small: site, building, floor, system/equipment, point.
  • Short, defined abbreviations from an agreed list (RAT, SAT, CHWV, SF-CMD…).
  • No spaces or special characters that some systems cannot handle.
  • The same name on the drawing, the controller, the graphic, the panel label and the trend log.

Tagging

Large and analytics-heavy projects add semantic tags (open schemes such as Project Haystack or Brick) describing what each point is — “air, temp, sensor, return” — so software can find points without parsing names. The naming discipline above is still the foundation.

⚒On site

  • Check the drawing revision before you start — wiring to an old revision is a common and expensive mistake.
  • Mark up changes in red on a site copy and hand them in for the as-builts.
  • If the name on the panel label, drawing and graphic differ, report it — it will confuse someone during a fault.
  • Keep a copy of the abbreviation list with the point list.

Point list / I/O schedule
Table of every point with its type, signal, range, alarms and terminal.
Network riser
Drawing of controllers and networks by floor.
As-built
Drawings corrected to match what was actually installed.
Revision
Version letter or number of a drawing.
Point naming convention
Agreed rules for building point names from fixed parts.
Semantic tagging
Describing points with standard tags (e.g. Project Haystack, Brick) so software can interpret them.

✓Check yourself

Try each one before opening the answer.

Fault scenario · what would you do?

You are sent to wire AHU-04's panel from drawing revision B. The site office has revision D on the wall. What do you do?

Always work from the current approved revision. Points, terminals or devices may have changed between B and D; re-wiring later costs far more than a phone call now.

  1. Which drawing tells you which network a controller is on?

    Show answer
    The system architecture / network riser diagram.

  2. Decode B1-L03-AHU01-SF-STS.

    Show answer
    Building 1, Level 3, AHU-01, supply fan run status.

  3. Name six columns of a good point list.

    Show answer
    Any six of: name/tag, description, I/O type, signal/device, range and units, normal state, alarm limits/priority, trend interval, controller and terminal, cable number, remarks.

  4. What are as-built drawings and why do they matter?

    Show answer
    Drawings corrected to show what was actually installed; they are what maintenance engineers rely on for the life of the building.

  5. Why should a point have the same name everywhere?

    Show answer
    So anyone can find and match it across drawings, controller, graphics, labels and trends without confusion.
