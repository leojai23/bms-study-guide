Practical lab 5

Reading Modbus registers

Talk Modbus to a simulated device on your own laptop, read registers, decode them, and make the classic mistakes on purpose.

Week 4 · Day 23About 90 min✓ Done

Time

About 90 min

You will produce

A table of decoded values, notes on the off-by-one and byte-order effects, and a short written explanation of each error you provoked.

Read first

5.3 Modbus RTU and Modbus TCP
5.2 IP address, subnet mask, device ID and baud rate
5.5 Communication troubleshooting
5.1 RS485 communication basics

What you need

  • A Windows laptop
  • A Modbus server simulator — e.g. ModRSsim2 (free)
  • A Modbus client — Modbus Poll (commercial, free trial), ModScan (commercial) or QModMaster (free)
  • Optional: a USB–RS485 adapter and a real Modbus device (or two adapters) for Part D

Tasks

Before you start

Practise on simulators, not live plant

Reading is harmless; writing to a real VFD or chiller changes how it runs. Only write to live equipment with permission and a plan.

Download tools only from their publishers' official websites. Screens and menu names differ between versions; the steps below describe what to set, which every tool offers in some form.

A · Set up a simulated device

Start the simulator in Modbus TCP mode on port 502 (your laptop's own address, 127.0.0.1). In its holding-register table, enter these values (documentation numbering):

B · Connect a client and read

In the client, create a Modbus TCP connection to 127.0.0.1 port 502. Set up a read of function 03 (read holding registers), slave/unit ID 1, starting at the first holding register, quantity 13, every 1 s.

C · Decode

Using the map, convert each value to engineering units: frequency, current, power, energy (combine 40004 and 40005 as one 32-bit value), the float at 40011–40012, and the signed temperature at 40013. Check them with the decoder:

Interactive tool

D · Make the mistakes on purpose

(1) Start the read one register later — what happens to every value? (2) Display 40011–40012 as a float with the words swapped. (3) Show 40013 as unsigned. (4) Read 3 registers starting beyond the simulator's configured table, and note the reply. (5) Change the slave ID to 2. (6) Write 400 to 40001 with function 06 and watch the simulator. Write down what each one looks like — on site you will recognise them instantly.

E · Optional: Modbus RTU over RS485

Connect a USB–RS485 adapter to a real device (or a second adapter running the simulator on a COM port). Match baud, parity and stop bits (e.g. 19200 8E1), wire A/B/common, terminate both ends, and repeat Part B with an RTU connection. If nothing answers, apply page 5.5 from the bottom up.
