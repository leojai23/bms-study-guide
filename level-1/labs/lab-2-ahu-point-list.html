Practical lab 2

AHU point list (DI, DO, AI, AO)

Build the complete point list for AHU-01 — the document every other part of the project is built from.

Week 3 · Day 21About 90 min✓ Done

Time

About 90 min

You will produce

A point list with every hard-wired, network and software point of AHU-01, plus an I/O summary and a controller choice.

Read first

4.2 The four I/O types: DI, DO, AI, AO
4.6 Reading BMS drawings and point names
3.8 Status devices: current switches and DP switches
6.5 Alarms: filter dirty, high and low temperature

What you need

  • A spreadsheet (Excel, LibreOffice or Google Sheets)
  • The AHU-01 schematic on the Level 1 overview
  • The blank template: point-list-template.csv

Tasks

1 · List the devices

From the AHU-01 schematic and device list, write down every device: sensors, actuators, the VFD, the filter switch, the fire interface. Next to each, note what the BMS needs from it (status, command, value).

2 · Name every point

Use the convention from page 4.6: B1-L03-AHU01- followed by a short point code (SF-CMD, RAT…). Keep the codes consistent — the same code means the same thing on every AHU.

3 · Fill in the columns

For each point: description, I/O type, signal and device, range or states, the normal state of digital inputs, alarm limits with delay and priority, trend interval. Use pages 3.x and 6.5 for the values.

4 · Add network and software points

Add the VFD's Modbus points (page 5.3) and the software points: setpoints, occupancy mode, schedule, reset command.

5 · Assign terminals

Group the inputs on universal inputs, outputs on DO and AO terminals, and leave spares. Give every field cable a number. Lab 1 uses this assignment.

6 · Summarise and size

Count points by type, add about 20 % spare, and state the minimum controller I/O you need.

Self-check

Tick each item when your work meets it. Ticks are saved in this browser.
